# Getting Started

1. Follow the [Setup Guide](../contributing/setup.md) to install dependencies and configure an untracked `.env`.
2. For the complete local stack, run `docker compose up --build -d`.
3. Open Studio at `http://localhost:4111`.
4. For host-side `npm run dev`, follow the [Database Guide](./database.md) to expose only the local database port and configure both storage URLs.

See the [Deployment Guide](../contributing/deploy.md) before deploying or reusing existing database volumes.
